# 01 — Find the problem

Use with any chat AI (Claude, ChatGPT). Fill in the `[brackets]`.

```text
We're a team of high-school students at a 3-day iOS hackathon (YIDH26). We have about 2 days to build
an iPad/iPhone app that solves ONE real problem for ONE real kind of person, using AI that runs on
Apple devices (on-device Foundation Models, Core ML/Create ML + sensors, or a Mac cluster running bigger open models).
Judges care most about real-world impact.

People we can actually talk to this week: [e.g. grandparents, younger siblings, our teachers, a parent's shop, the school nurse]
Things we're interested in: [e.g. health, school, food, money, the environment]

1. Suggest 8 specific problems these people really have. Write each as "[who] struggles with [what] because [why]".
2. For each one, give: how we could check it's real (a question to ask them), what the app would do in one sentence,
   which AI option fits and why, and how we'd measure impact (time saved, money saved, mistakes avoided).
3. Rank them by: real impact, can a demo work in 2 days, and good fit for on-device AI.
Don't suggest anything that needs login, real patient data, or a backend server.
```

**After this:** go ask a real person the "check it's real" question before you commit to an idea.
